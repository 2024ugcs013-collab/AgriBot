# Model Weights Directory

This directory stores the neural network weights for the YOLOv4 detector and DenseNet-121 baseline.
Because neural network weights files exceed GitHub's standard 100 MB file limit, binary weights are excluded from Git version control.

### Expected Weight Files:
1. **`yolov4.conv.137`** (~170 MB): Pretrained ImageNet backbone weights for CSPDarknet53.
   - Download official weights:
     ```bash
     wget https://github.com/AlexeyAB/darknet/releases/download/darknet_yolo_v3_optimal/yolov4.conv.137 -P weights/
     ```
2. **`yolov4-custom-potato_best.weights`** (~256 MB): Best checkpoint trained on the potato disease dataset.
   - Checkpoints are saved automatically during training to `weights/backup/yolov4-custom-potato_last.weights`.
3. **`densenet121_best.pt`** (~27 MB): PyTorch weights for the fine-tuned DenseNet-121 baseline.
   - Generated by running:
     ```bash
     python scripts/train_densenet_baseline.py
     ```
